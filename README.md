# AI and Manufacturing Training

This repository contains materials for the **AI & Manufacturing Workshop**, a hands-on training designed to help manufacturing professionals understand and apply artificial intelligence in real production environments.

The workshop focuses on **practical, applied AI techniques** that organizations can use to improve operations, reduce downtime, and support workforce productivity.

## Training Format
- 3 Days  
- 3 Hours per Day  
- 9 Hours Total  

Each session introduces key concepts and includes demonstrations or hands-on activities.

# Workshop Sessions

## Day 1: Prompting, LLMs, and AI Skills
**Theme:** Mastering AI interaction and building reusable AI skills for manufacturing

| Time | Block |
|---|---|
| 0:00 to 0:45 | AI fundamentals, prompting with the RTFC framework (Role, Task, Format, Constraints), and spotting hallucinations |
| 0:45 to 1:55 | AI skills: why Gems and custom GPTs are becoming skills, then build and test your own skill |
| 1:55 to 2:00 | Break |
| 2:00 to 3:00 | Local LLMs with LM Studio (led by Clayton) |

Topics covered:

- AI fundamentals: Artificial Intelligence, Machine Learning, and core AI domains
- Effective prompting strategies for LLMs like ChatGPT, Gemini, and Claude
- The RTFC Framework (Role, Task, Format, Constraints)
- Identifying and preventing AI hallucinations in technical environments
- AI skills: reusable instructions plus reference files in one SKILL.md file that works in Claude and Gemini
- Hands-on: Building a skill for SOPs, troubleshooting, or reporting
- Local LLMs: running a model on your own machine with LM Studio

# Tools Used in the Workshop

Participants interact with practical and accessible AI tools, including:

- Orange Data Mining  
- Google Teachable Machine  
- TensorFlow  
- LLM tools (ChatGPT, Gemini, Claude, Codex)
- LM Studio (local LLMs)  
- Open manufacturing datasets  

These tools allow participants to experiment with AI concepts without requiring advanced programming experience.

- Process improvement teams  
- Workforce development organizations
